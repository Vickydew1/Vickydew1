## `01 / SYSTEM PROFILE`

I’m **Vicky Dewangan**, a Forward Deployed Engineer at **AccuKnox**. I work where software engineering, cloud infrastructure, and security meet—helping turn complex technical systems into practical solutions.

My engineering interests center on **cloud-native security, Kubernetes runtime protection, and DevSecOps**. I enjoy understanding how systems behave in real environments, finding the sharp edges, and building tools and workflows that make secure engineering more achievable.

Outside the terminal, I care about the systems we all depend on: **our climate, biodiversity, and shared future**. I’m connected with youth and global communities working on these challenges, including YOUNGO, the Global Youth Biodiversity Network (GYBN), and HPAIR.

> **My north star:** build technology that is resilient by design—and contribute to a world that is resilient beyond technology.
